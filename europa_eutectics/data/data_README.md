# Europa eutectic data

This folder contains summaries and visualizations of 45 Europa ice-shell
simulations generated with the GAIA code (Hüttig et al., 2013), together with
study-wide CSV tables documented in [study_csv_README.md](./study_csv_README.md).

## Simulation structure

The simulations are organized into four parameter-study groups. Each simulation
has one JSON summary and associated images in the group's `vis/` folder.

| Study group | # of Simulations | Parameter focus |
| --- | ---: | --- |
| `shell_visc/` | 20 | Ice-shell thickness (D) and reference viscosity ($\eta_{ref}$) |
| `shell_thermal_cond_expan/` | 15 | Variable Thermal conductivity (k(T)) and Thermal Expansivity ($\alpha(T)$) |
| `shell_complex_rheo/` | 5 | Complex rheology ($\eta_{mix}$) |
| `shell_tidal/` | 5 | Tidal heating (H) |

The baseline `shell_visc/` group covers all combinations of shell thicknesses (20-60 km) and reference viscosities ($10^{12}$-$10^{15} ~Pa \cdot s$). All study groups span the same shell thicknesses, and have a fixed reference viscosity of $10^{13} Pa \cdot s$. Simulations in the `shell_complex_rheo` study mention the equivalent grain size of the ice in the filename. 

The thermal-property study is further divided into:

| Subfolder | Thermal conductivity (k) | Thermal expansivity ($\alpha$) | # of Simulations |
| --- | --- | --- | ---: |
| `constK_varA/` | Constant | Variable | 5 |
| `varK_constA/` | Variable | Constant | 5 |
| `varK_varA/` | Variable | Variable | 5 |

JSON filenames use the simulation case ID followed by `_data.json`, for example
`Europa_D20km_eta1e+13_data.json`. The `D` portion identifies shell thickness,
and tidal cases include `_Tides`. Each group or thermal-property subfolder
contains its own `vis/` directory, containing small visuals as standard output per-simulation. These are genreated by the `save_*.py` files found in `src/util/`. 

## JSON simulation summaries

Each JSON file is an object containing metadata, time series, and derived
fields. Fields named `avg_` are derived from the final 10% of saved simulation
outputs. Two-dimensional fields are stored as nested arrays with depth layers
as rows and lateral shell positions as columns; their dimensions vary by
simulation.


| Field | Type and shape | Description |
| --- | --- | --- |
| `path` | `str` | Path to the original GAIA simulation directory on the system where the summary was saved |
| `caseID` | `str` | Simulation case identifier |
| `parent_dir` | `str` | Original parent directory of the simulation |
| `dim_data` | `dict` | Simulation parameters and dimensional constants, such as radii, temperatures, viscosity, and Rayleigh number; additional parameters depend on the study |
| `times` | `array_like` | Saved output times, in millions of years |
| `avg_temp_2d` | `array_like`, shape `(n_layers, n_shells)` | Time-averaged temperature field, in kelvin |
| `avg_deformation_2d` | `array_like`, shape `(n_layers, n_shells)`, or `None` | Most frequent deformation index at each grid cell over the averaged outputs, or `null` when the field is unavailable |
| `avg_stagnant_lid_depth` | `array_like`, shape `(n_shells,)` | Time-averaged stagnant-lid depth at each lateral position, in kilometers |
| `avg_Nusselt_top`, `avg_Nusselt_bottom` | `float` each | Time-averaged top and bottom Nusselt numbers |
| `avg_Ra_interior` | `float`, when present | Time-averaged interior Rayleigh number; present in some summaries |
| `avg_rms_velocity` | `float` | Time-averaged RMS velocity, in centimeters per year |
| `rms_velocity_temporal` | `array_like`, 1D | RMS velocity time series, in centimeters per year |
| `eta_ref` | `float` or `int` | Base-10 logarithm of the reference viscosity in Pa s |
| `Ra` | `float` | Reference Rayleigh number |
| `D` | `float` or `int` | Reference shell thickness, in kilometers |
| `eutectics` | `array_like`, shape `(n_eutectics,)` | Eutectic temperatures used to calculate interfaces, in kelvin |
| `attenuation_params` | `list` of `[float or int, str]` pairs | List of `[threshold, model]` pairs; thresholds are in dB and models are `Low Loss` or `High Loss` |
| `final_time` | `float` | Final output time, in millions of years |

The files store interface parameters rather than the calculated interface
arrays. `GaiaSim.load_from_json` reconstructs the interfaces(src/eutectic_interface.py or src/attenuation_interface.py) using the saved
temperature data. 

## Visualizations

Each `vis/` folder contains PNG files prefixed with the corresponding case ID.
The images are generated by `src/util/save_gaia_fields_of_study.py` from the
simulation summaries and reconstructed interfaces. Each simulation has five
images:

| Filename suffix | Contents |
| --- | --- |
| `_Temperature (K).png` | Two-dimensional temperature field averaged over the final 10% of saved outputs, in kelvin |
| `_eutectic_interfaces.png` | Eutectic interface depths versus distance along the equator, both in kilometers; dashed lines indicate their mean depths |
| `_Two-Way Attenuation (dB) - Low Loss.png` | Two-dimensional cumulative two-way attenuation for the low-loss model, in decibels |
| `_Two-Way Attenuation (dB) - High Loss.png` | Equivalent attenuation field for the high-loss model |
| `_rms_velocity.png` | RMS velocity in centimeters per year versus time in millions of years; the dashed line shows the average over the final 10% of saved outputs |

Attenuation values are capped at the configured threshold (100 dB for the
saved simulations) when plotted. Complex-rheology simulations also have a
`_Deformation Index.png` image showing the most frequent deformation index at
each grid cell over the averaged outputs.
